Move your data across, and keep it safe

Your data lives in a different place from your code. Understanding that one fact makes everything else here easy.

Move your data from the Artifact to the live site

  1. Open the Artifact on claude.ai, unlock it, and click Export Backup. Accept the download prompt.
  2. Open your new site. Because it has no data yet, it shows the first-run screen.
  3. Click Import a backup file, choose the file, and enter the same unlock PIN you used in the Artifact (and the setup code, if you set one).
  4. The site checks the PIN by decrypting the file, saves it, and opens your data, exactly as it was.
Do the import straight after the first deployUntil data exists, anyone who finds the address sees the first-run screen and could create their own data there. Import yours right away, or set SETUP_CODE in Netlify first.

Three layers of protection

1. Export Backup (for you)

The button in the app downloads an encrypted copy any time. Keep a few in a safe folder or cloud drive. They're useless without the PIN, so they're safe to store.

2. Automatic version history (on the server)

Every save keeps the previous version, up to the last 30. If something goes wrong, for example a bad import or an accidental mass delete, Claude can roll back to any of them.

3. The admin backup door (for Claude)

A protected endpoint, /api/backup, lets Claude Code copy the live data down to your computer, list the saved versions, and restore one. It needs the ADMIN_KEY, and it only handles the encrypted data. Even with the key, nobody can read the figures without the PIN.

The admin script's actions
Backup    save the live data to a dated file in the backups folder
List      show the live revision and the server's saved versions
Restore   put back a backup file or a saved version (the one it replaces is kept too)
Prompt: back up now
Back up the live data for <app name> with the admin script and tell me the file name and revision.
Prompt: undo a mistake
Something went wrong with <app name> after <time / what happened>. Back up the current live data first,
then list the saved versions and restore the last one from before that. Tell me what you restored.
