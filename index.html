Beginner's guide

Build a web app with Claude and put it live, start to finish

This guide follows one real project from an idea typed into Claude to a live, mobile-friendly website with a secure login, encrypted data, history, reports and backups. You don't need to have done any of this before.

After that it's a loop: you ask Claude for a change, Claude backs up the live data, edits the code and pushes it to GitHub, and Netlify updates the site within a minute or two. Your data is never touched by a code update.

No data to store? Take the quick pathFor a guide, portfolio, calculator or other simple site that doesn't need a shared database, skip Netlify and publish straight to free GitHub Pages: see Quick path: simple sites.

What you'll end up with

  • A real website on its own address (for example yourapp.netlify.app) that works on phones, tablets and computers.
  • A PIN login, with the data encrypted in the browser so the server only ever holds scrambled data.
  • A transaction log of every change, monthly archives, and PDF reports.
  • An export and import button, so data can move between versions and devices.
  • Automatic deploys: every change Claude publishes goes live by itself.
  • An admin backup door and automatic version history, so a mistake can always be undone.
