# Deploy apps with Claude

A beginner's step-by-step guide to building a web app with Claude, publishing it to GitHub from Claude Code, and running it live on Netlify with a secure login, encrypted data, history, reports and backups.

Read it at **https://edasob1.github.io/claude-app-deploy-guide/**

Plain HTML, CSS and a little JavaScript; no build step. Served by GitHub Pages from the `main` branch.
