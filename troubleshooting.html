Troubleshooting

The problems people actually run into on this journey, and how to fix each one. When in doubt, describe exactly what you saw to Claude, ideally with a screenshot.

In the Artifact

"Print" or "Save as PDF" does nothing

The print dialog is blocked inside claude.ai's frame. Ask Claude to generate the PDF in the page with jsPDF and offer it through the Artifact's download capability instead.

Someone I shared it with sees "could not be loaded"

They need to be signed in to Claude, and invited from the Share menu. To edit (not just view), give them Contributor access or above.

The phone keyboard doesn't open for the PIN

Phones only open their keyboard when the person taps a field. Ask for an on-page number keypad on touch screens.

GitHub

403 Resource not accessible by personal access token

The token can't reach that repo or lacks a permission. Edit the token on GitHub: add the repo under Repository access (or choose All repositories), and set Contents to Read and write. Creating repos also needs Administration: Read and write.

Switching on GitHub Pages gives 403

The token needs both Pages: Read and write and Administration: Read and write. Ask Claude to read the X-Accepted-GitHub-Permissions header on the failed request: GitHub lists exactly which permissions it wanted. Or switch Pages on by hand under Settings → Pages.

401 Bad credentials

The token has expired or was deleted, or the file has extra text in it. Make a new token and put only the token in the file.

Claude refused to read an existing token file

Claude Code's safety checks may block reading a credential that was set up for something else. That's deliberate. Make a dedicated token for this project and tell Claude its file path.

Netlify

The site says the data "could not be loaded"

The page couldn't reach /api/vault. Check Deploys for a failed build, and Logs → Functions for errors. Make sure the repo contains netlify/functions/ and package.json.

/api/backup returns 503

ADMIN_KEY isn't set, is shorter than 32 characters, or the site hasn't been redeployed since you added it. Add it, then Trigger deploy.

A save says "changed on another device"

Two devices edited at once. The app refused the second save instead of overwriting, and reloaded the latest figures. Make the change again.

A change didn't appear on the live site

Look at Deploys: if the newest deploy failed, the old version is still live. Send the build log to Claude. If it succeeded, reload the page; phones sometimes keep the old page open in the background.

PowerShell (Windows)

Unexpected token '?'

That command was written for PowerShell 7 and you ran it in Windows PowerShell 5.1. Ask Claude for a 5.1-compatible version, or install PowerShell 7.

Commands starting with ! fail in a normal PowerShell window

The ! prefix only works when typed into the Claude Code prompt. In a separate PowerShell window, paste the command without the !.

Data

"Incorrect PIN" on import

Imports need the unlock PIN the data was created with, not a second PIN used for risky actions.

Someone set up the app on my site before I imported my data

Ask Claude to back up that record and restore yours over it with the admin script, then set SETUP_CODE in Netlify for next time.

Security checklist before you share the link

  • Unlock PIN is 6 to 8 digits and stored in a password manager.
  • Your data was imported (or SETUP_CODE is set) so nobody else can claim the first-run screen.
  • ADMIN_KEY is set in Netlify and kept in a file outside the project.
  • No token, key or PIN appears in the repo, the chat, or screenshots.
  • A first admin backup has been taken successfully.
  • The GitHub token has an expiry date and only the permissions listed in Step 3.
Written from a real project built with Claude Code, Claude Artifacts, GitHub and Netlify. Services change their menus from time to time; if a button has moved, the setting usually has the same name.
