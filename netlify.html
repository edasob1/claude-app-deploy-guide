Step 5

Go live on Netlify

Netlify takes the code from GitHub, runs the server functions, stores the data and gives the app a web address. You connect it once; after that it updates by itself.

Connect the repository

  1. Sign in at app.netlify.com (signing up with your GitHub account makes this smoother).
  2. Choose Add new project → Import an existing project → GitHub.
  3. If asked, authorise Netlify on GitHub and give it access to the new repository. If your repo is on a different GitHub account from the one you signed in with, use Configure the Netlify app on GitHub to add that account or repo.
  4. Pick the repository. Leave Build command and Publish directory empty: the repo's netlify.toml sets them.
  5. Choose a site name; it becomes the address, for example myapp.netlify.app. Click Deploy.

Add the secrets (environment variables)

Secrets live in Netlify's settings, never in the code. Go to Site configuration → Environment variables → Add a variable:

NameValueNeeded?
ADMIN_KEYThe contents of the admin key file Claude generatedYes, for backups and restores
SETUP_CODEAny code you chooseRecommended: stops a stranger setting up the app before you import your data
New variables need a redeployEnvironment variables only reach the functions after the next deploy. Go to Deploys → Trigger deploy → Deploy site after adding or changing one.

Check it's working

Send Claude the address and ask it to check:

Prompt: verify the live site
The site is live at <https://yourapp.netlify.app>. Save that URL for the admin script, then check:
1. the page loads the new version,
2. /api/vault responds (404 is fine before any data exists),
3. /api/backup refuses a request without the admin key,
4. a backup with the admin key works (once data exists).
Report each result.

A healthy result looks like this:

CheckExpected
Page200, new version
/api/vault404 before import, 200 after
/api/backup without key403 forbidden (a 503 means ADMIN_KEY isn't set or the site wasn't redeployed)
Admin backupA file saved in your backups folder

Optional: your own domain

Under Domain management you can add a domain you own (for example app.example.com). Netlify walks you through the DNS record and sets up HTTPS automatically.

Keep it out of search enginesThe site includes a noindex tag so search engines won't list it, but that's not security. The PIN and encryption are what protect the data.
